# 🎯 NEET Dashboard

A comprehensive strategy dashboard for NEET preparation.

## 📁 Project Structure

```
neet/
├── index.html          # Main HTML file
├── css/
│   └── style.css       # All styles
├── js/
│   └── script.js       # All JavaScript
├── assets/             # Images, icons, etc.
└── README.md           # This file
```

## 🚀 Getting Started

### Local Development
1. Install VS Code extensions (Live Server)
2. Open this project in VS Code
3. Right-click `index.html` → "Open with Live Server"
4. Make changes → Browser refreshes automatically

### Deployment
- Push to GitHub
- Connect to Vercel
- Website goes live!

## 📝 Notes

- `js/script.js` — Add your JavaScript
